[ API / Middleware ]
        ↓
[ SecurityEventBuilder ]
        ↓
[ SecurityMiddleware.evaluate(event) ]
        ↓
[ Rule Engine ]
        ↓
[ LLM Evaluator ]
        ↓
[ RiskDecision ]

2. モジュール設計
2.1 SecurityEventBuilder

入力データを SecurityEvent 形式に正規化

必須項目検証

不足情報の signal 付与

2.2 SecurityMiddleware
evaluate(event)

処理概要

schema 検証

フォールバック判定

ルール評価

LLM 評価（必要時）

結果統合

3. データ構造
3.1 RiskDecision
項目	型	説明
riskLevel	string	LOW / MEDIUM / HIGH / CRITICAL
suggestedAction	string	ALLOW / CHALLENGE / BLOCK
confidence	number	0.0〜1.0
signals	array	判断根拠
4. エラーハンドリング
ケース	処理
schema 不正	MEDIUM + CHALLENGE
LLM 失敗	ルール結果を採用
