| Event名               | 対応する状態遷移  | 業務的意味                      | 判断主体      | 発火条件（成立根拠）                                  | ERPとの関係           |
| -------------------- | --------- | -------------------------- | --------- | ------------------------------------------- | ----------------- |
| ApplicationAccepted  | S01 → S02 | 買主の申込意思が業務上正式に受理された事実      | 買主（業務担当者） | 申請内容が所定の受付要件を満たし、受付完了が業務担当者により確定したこと        | ERP未連携（業務システム内完結） |
| ContractConcluded    | S02 → S03 | 売主・買主双方の合意により契約が有効に成立した事実  | 売主・買主     | 締結記録が確定し、ERP（販売管理）にて契約完了が確認できること            | ERP（販売管理）参照       |
| PaymentCompleted     | S03 → S04 | 契約に基づく金銭授受が業務上完了した事実       | 売主（経理担当者） | 入金確認および決済完了が経理担当者により承認され、ERP にて決済完了が確認できること | ERP（販売管理）参照       |
| TransactionCompleted | S04 → S05 | 当該売買契約に関する業務上の取引がすべて完了した事実 | 売主・買主     | 商品引渡・在庫処理等が完了し、ERP（在庫／引渡管理）にて完了確認ができること     | ERP（在庫／引渡管理）参照    |

3️⃣ State Machine Code（最终）
export function transition(
  current: TransactionState,
  eventTitle: string
): TransactionState {

  const table: Record<TransactionState, Record<string, TransactionState>> = {
    S01: { ApplicationAccepted: TransactionState.ApplicationAccepted },
    S02: { ContractConcluded: TransactionState.ContractConcluded },
    S03: { PaymentCompleted: TransactionState.PaymentCompleted },
    S04: { TransactionCompleted: TransactionState.TransactionCompleted },
    S05: {}
  };

  const next = table[current]?.[eventTitle];
  if (!next) {
    throw new Error(`Invalid transition: ${current} → ${eventTitle}`);
  }
  return next;
}

async function handleEvent(
  aggregateId: string,
  event: { eventId: string; title: string }
) {
  const current = await stateRepo.get(aggregateId);

  const next = transition(current.state, event.title);

  await stateRepo.save({
    id: aggregateId,
    state: next,
    lastEventId: event.eventId
  });
}
