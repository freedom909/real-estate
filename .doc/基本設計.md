Security Event Risk Evaluation 基盤

1. システム概要

本系统用于对业务 / 认证相关的 SecurityEvent 进行风险评估

输出统一的 RiskDecision（riskLevel / suggestedAction / confidence）

支持规则 + LLM 推断的混合模型

2. 全体アーキテクチャ
[ API / Middleware ]
        ↓
[ SecurityEventBuilder ]
        ↓
[ SecurityMiddleware.evaluate(event) ]
        ↓
[ Rule Engine ] → [ LLM Evaluator ]
        ↓
[ RiskDecision ]

3. データ設計（SecurityEvent）
项目	类型	必须	说明
eventId	string	◯	唯一事件ID
action	string	◯	auth / business
actor	object	◯	行为主体
context	object	◯	请求上下文
resource	object	◯	操作对象
signals	object	◯	风险信号
payload	object	△	已脱敏业务数据
history	object	△	关联历史事件
4. 処理フロー（evaluate）

输入 SecurityEvent

schema 验证

缺失字段补 signal

执行规则判断

调用 LLM（必要时）

合并决策结果

输出 RiskDecision

5. リスク判断ルール（概要）
条件	       风险
多次登录失败	HIGH
未认证敏感操作	CRITICAL
上下文不足	MEDIUM
