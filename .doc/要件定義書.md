要件定義書（SecurityEvent）
1. 目的（Purpose）

本ドキュメントは、不動産（real-estate）システムにおける
セキュリティイベント評価機能の要件を定義するものである。

本機能は、ユーザーの認証操作および業務操作に対して
リスク評価を行い、システムが適切なセキュリティ対応を
判断するための情報を提供することを目的とする。

本機能は 判定のみを行い、実際の制御や遮断処理は行わない。

2. 適用範囲（Scope）

本要件は、以下の処理に適用される。

認証関連操作（ログイン、認証試行等）

業務操作（物件作成、更新、投稿等）

API 呼び出しおよび内部業務アクション

3. 用語定義（Definitions）
用語	説明
SecurityEvent	単一のユーザー操作を表すセキュリティ評価用イベント
Actor	操作主体（ユーザーまたは匿名利用者）
Signal	行動パターンや異常検知に関する補助情報
RiskLevel	セキュリティリスクの評価結果
SuggestedAction	推奨される対応方針（制御は含まない）
4. SecurityEvent 構造要件
4.1 必須項目（Required）

SecurityEvent は、以下の項目を 必ず 含むものとする。

4.1.1 基本情報
項目名	型	説明
eventId	String	イベントを一意に識別するID
action	String	認証または業務アクション種別
4.1.2 Actor（操作主体）
項目名	型	説明
userId	String / Null	ユーザーID（未認証時は null）
role	String	ユーザーロール
isAuthenticated	Boolean	認証済みか否か
4.1.3 Context（リクエスト情報）
項目名	型	説明
ip	String	リクエスト元 IP アドレス
userAgent	String	ユーザーエージェント
requestId	String	リクエスト識別子
4.1.4 Resource（操作対象）
項目名	型	説明
type	String	リソース種別
id	String / Null	リソース識別子
4.1.5 Signals（評価補助情報）
項目名	型	説明
signals	Object	行動・異常検知に関する情報
4.2 任意項目（Optional）

以下の項目は、必要に応じて付与することができる。

4.2.1 Payload
項目名	型	説明
payload	Object	サニタイズ済み業務入力

※ 機密情報（パスワード、トークン等）を含めてはならない。

4.2.2 History
項目名	型	説明
history	Object	過去関連イベント情報
recentEvents	Array	直近イベント一覧
5. 判定結果に関する要件
5.1 リスクレベル定義
RiskLevel	説明
LOW	通常行動と判断される
MEDIUM	不審要素が存在するが断定できない
HIGH	不正・攻撃の可能性が高い
5.2 推奨対応（SuggestedAction）
Action	説明
ALLOW	通常処理を継続
CHALLENGE	追加検証を要求
FLAG	記録・通知のみ行う

※ 本機能は 処理の遮断や強制制御を行わない。

6. 不足・不正データ時の既定動作（Fail-Safe）

以下の場合、本機能は 保守的判断 を行うものとする。

必須項目が不足している場合

フォーマットが不正な場合

判定に必要な情報が不十分な場合

既定動作

RiskLevel：MEDIUM

SuggestedAction：CHALLENGE

confidence：0.5 以下

signal："insufficient_context" を含めること

7. 非機能要件（Non-Functional）

本機能は ステートレス であること

単一イベント単位で評価を行うこと

判定理由は簡潔かつ説明可能であること

外部知識や推測を用いないこと

8. 補足事項

本要件定義書は、
セキュリティイベント評価機能に関する 唯一の要件定義 とし、
設計・実装・テストは本定義に準拠するものとする。
